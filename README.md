# 香港 × 澳门 2026｜规划版 V3

面向两位学生旅客的 2026 年 10 月 2–7 日港澳 6 天 5 晚规划页面。保留 Travel-Plan-Page 的纸张感、深色信息卡、时间线和移动端优先风格，并加入：

- OpenTopoMap / OpenStreetMap 真实地形与街道底图
- 香港、澳门与跨城路线总览
- 6 天逐时段安排与每站导航
- 主要景点实景照片、推荐理由、适合人群、停留时间、拥挤度、雨天适配与删减建议
- 人均 ¥3,000 / ¥4,000 / ¥5,000 三档双人预算
- 两人、双床房、成都与长沙分别出发等旅行信息
- 航班、酒店、返程方案继续标注“待确认”
